# CHARACTER — 游戏设定文档（GDD 摘要）

> 世界观、舰娘人设基调、玩法循环。写 UI 文案与美术生成时参照。

## 世界观

**《美舰收藏》**：玩家扮演太平洋舰队提督（Commander），指挥美国海军各舰拟人化的"舰娘"
（美舰少女），对抗来自深海栖舰的红衣舰队（以日本海军涂装为原型改编的"深海军"——深红色的架空敌军）。

舞台为 1941-1945 年太平洋战争相关海域的架空重构：珍珠港近海、所罗门海、莱特湾等。

## 舰娘命名规则

- 双名制：英文舰名（大写）+ 中文译名。UI 显示中文为主、英文为辅。
- 例：ENTERPRISE 企业、IOWA 爱荷华、FLETCHER 弗莱彻、ATLANTA 亚特兰大。

## 拟人人设基调（用于 SVG 生成）

- 每个舰娘 = 半身像卡片：海军制服（白色/藏蓝）+ 领巾 + 舰级徽章 + 个人色系
- 发色/发型程序化区分：BB 长发端庄、CV 双马尾/长卷、DD 短发俏皮、SS 深色冷调
- 背景色按舰级：BB 海军蓝、CV 天蓝、CA 深灰蓝、CL 浅蓝、DD 青、SS 墨黑绿、AV 紫
- 右下角绘制军舰侧影水印，左上角舰级代码徽章
- 立绘文件名 = 舰船 id：`public/art/portraits/<id>.svg`

## 阵营与敌军

- 玩家：美国海军（白星徽章 ★★★★★ 蓝底）
- 敌军：深海舰队（红黑涂装，boss 用"鬼/姬"级命名：如 深海空母水鬼、深海战列栖姬）
- 友军支援（演习/活动）：蓝星 NPC 舰队

## 核心玩法循环（对应分析报告）

```
建造/开发/掉落 → 编成舰队 → 补给 → 出击海域(昼夜战斗) → 经验/掉落/资源点
      ↑                                                        ↓
   远征/任务/自然恢复 ←────────────────── 入渠修理/补给/疲劳回复
```

- 周期循环：日常任务每日 05:00 重置；远征 30min~12h；资源自然恢复
- 养成深水区：等级 → 改造(改/改二) → 近代化改修喂属性 → 装备开发/改修
- 演习：每日多次免费模拟战练级（不耗资源不受伤）

## 首版内容清单

- 舰船：约 45 艘（BB 13 / CV 9 / CVL 3 / CA 7 / CL 6 / DD 12 / SS 4 / AS 1），多数有 改/改二 形态
- 装备：约 45 件（主炮/副炮/鱼雷/舰战/舰攻/舰爆/水侦/电探/高角炮/声呐/爆雷/穿甲弹/设备）
- 海域：1-1 母港近海 / 1-2 所罗门哨戒 / 1-3 珍珠港近海 / 1-4 近海防卫线（镇守府海域）
  2-1 图拉吉急袭 / 2-2 铁底湾海峡 / 2-3 圣克鲁斯海域 / 2-4 瓜达尔卡纳尔攻略（南西群岛海域）
  3-1 北大平洋哨戒 / 3-2 基斯卡岛近海 / 3-3 阿图岛方向 / 3-4 北方海域全域（北方海域）
- 远征：8 个（15min ~ 12h）
- 任务：日常 9 + 周常 9 + 月常 4 + 一次性 25（含解锁链）
- 演习：每天 5 个 NPC 对手（强度梯度）
